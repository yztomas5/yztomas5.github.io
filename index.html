Featured · Data persistence

Vault

A player-data package for live Roblox games, built on its own save engine and tested against a simulated Roblox before it touches real players.

  • Session-locked profiles: one server owns each profile at a time.
  • Saves in ProfileStore’s format, so a live game can migrate one server at a time.
  • Market module for Robux purchases: a receipt ledger and a confirmed save before Roblox is notified. No double charges, no lost purchases.
  • Lune test lab that simulates crashing servers, failing data stores and players hopping between servers.
